# 更新日志

## 0.1.0（开发中）

- 建立 uni-app X 蒸汽模式组件库结构与 du- 前缀。
- 增加亮色、暗色、自动主题及局部样式变量。
- 提供主题容器、按钮、受控输入框参考组件。
- 提供独立 API 文档；API 状态为 experimental。
- 正式发布前按实际平台证据填写兼容性，不以 Web 结果代替 App 验证。

### 三组件能力补齐

- Button：图标与命名插槽、数值/token/响应式尺寸、圆形/无底色/无样式、阴影、状态样式、真实 HTML 表单属性与 Vue 事件。
- Input：受控/非受控、类型与确认键、只读/表单属性、光标与选区、占位/选区样式、焦点方法及输入装饰插槽。
- ConfigProvider：局部配置与命名主题、继承/反转/重置、默认值、方向/语言、断点上下文和监听清理。
- 保留旧用法，逐项写明原生与 Web 的技术差异；实验状态和市场认证边界不变。
