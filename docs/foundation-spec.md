# Dudu UI 基础架构验收

目标：将现有示例工程升级为面向 uni-app X 蒸汽模式、可通过 uni_modules 分发、可持续增加组件的组件库。库名 dudu-ui；组件、样式和 CSS 变量前缀 du-。

本次交付基础架构及少量参考组件，不把规划中的完整组件清单冒充已经实现，也不宣称未经证明的“世界第一”。

## 可观察的验收结果

1. 设计变量只有一个编辑来源，生成亮色/暗色/自动主题与组件默认值；校验生成文件漂移及文字对比度。局部嵌套主题互不污染。
2. Button 兼容现有调用；提供尺寸、语义状态、键盘操作和主题支持。新增 Input 演示 v-model、可见标签、错误/帮助反馈及内部样式定制。组件不执行业务提交、联网或数据持久化。
3. 每个组件目录有源码、元数据和 API 文档；命令可安全创建新组件及独立示例页，不覆盖已有文件。目录和组件清单由真实文件生成。
4. check/test/build 命令可以复用；生成文件陈旧、错误组件命名、不合规模块引用或发布包夹带示例配置会失败。静态扫描不是 UTS 类型检查，官方编译独立执行。
5. 本地分发包只含 uni_modules/dudu-ui，能在全新的消费者工程中通过 easycom 编译，不依赖原示例工程的全局样式或别名。
6. 发布前检查把未确定许可证/作者、缺失实际平台证据视为待处理项；不自动上传、提交或改变用户账号。未知端不宣称已支持。
7. Web 验证亮/暗/自动主题、交互状态、表单数据流、键盘及窄屏布局。原生编译尽可能验证；真机与性能测量分别记录。

## 技术边界

HBuilderX 5.26，uvue + script setup lang="uts"，官方编译器；零新增运行时依赖。主题使用 5.25+ 蒸汽支持的 prefers-color-scheme 媒体查询。应用导航栏通过独立 theme.json；组件库不修改宿主 manifest/pages/theme 配置。

默认视觉暂采用中性、精致、清晰的移动端语言，字体使用系统字体，无字体下载与外部资源。品牌色可覆盖，触控主按钮以 48px 为基线。视觉偏好反馈可以调整变量，无需重写组件架构。

## 三组件属性对齐（本轮）

验收范围与逐项默认值以三组件 readme 和 docs/current-component-parity.md 为准。保留原调用；真实图标/插槽、标准表单、受控拒绝回写、非受控默认值、主题默认值/反转/重置/继承、RTL 和断点联动必须通过运行验证；技术差异必须写清楚，不以空 prop 算完成。用户已授权本轮通过验收后提交并推送全部项目代码至 beefnoodleszzz/dudu-ui 的 main，不包含编译缓存或凭据；插件市场发布尚未授权。
